# Candidate Response Evaluation & Grading System

## Overview
This project simulates a real-world Data Operations workflow similar to assessment and evaluation systems.

The system:
- Collects candidate written responses
- Cleans and standardizes data
- Applies evaluation guidelines
- Performs large-scale grading
- Conducts reliability analysis
- Integrates SQL database for analytics

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- SQLite (SQL inside Python)

## Key Features
- Standardized evaluation framework
- Automated scoring logic
- Statistical reliability analysis (Mean, Variance, Standard Deviation)
- SQL queries (Aggregation, Subqueries, Group By)
- Score distribution visualization

## Project Structure
- candidate_responses.csv
- graded_responses.csv
- Candidate_Response_Grading.ipynb

## Learning Outcome
This project demonstrates data cleaning, evaluation, grading, database integration, and analytical validation processes used in Data Operations and ML data preparation workflows.
